# TUTORIAL — Using Claude Code (plain English)

You don't need to know how to code. You describe what you want; Claude does the
technical part. This page is everything you actually need to know.

## What Claude Code is

A chat with an AI that can DO things on your computer — create files, build
little tools, organize projects, search the team knowledge brain — not just talk.
You open it in your workspace folder and type like you'd text a very capable
coworker.

## How to ask for things

Describe the OUTCOME, not the method. You don't need the right words.

- Good: "I want a one-page plan for reaching out to 50 pro shops next month."
- Good: "Build me something that tracks which clubs I've called and when."
- Good: "I don't know if this idea is good — pressure-test it."

If Claude asks you a question, just answer honestly. "I don't know" is a fine
answer — it'll pick a sensible default and tell you. Claude is set up to ask you
a couple of questions before building anything real — answering them is exactly
how you get results that fit what you actually wanted, so don't rush past them.

## The board — your unfair advantage

For anything real (a campaign, a plan, a new tool), say:
**"run this through the board."**

Claude will then consult three specialists, in order:

1. **The strategic advisor** — a blunt business brain. Decides if the idea is
   worth doing and what the smart version looks like.
2. **The senior engineer** — turns the idea into a concrete step-by-step plan.
3. **The red team** — attacks the finished plan as hard as possible. If the plan
   survives, you can trust it. If it doesn't, you just saved yourself weeks.

You can also call any seat alone: "what would the strategic advisor say about
pricing this at $500?" or "red-team this email idea."

## The knowledge brain

The brain is thousands of tactics pulled from hundreds of hours of top operators
teaching marketing, sales, ads, and content. Ask things like:

- "Search the brain for cold email opening lines."
- "What does the brain say about pricing objections?"
- "Pull everything the brain has on TikTok hooks."

Every answer cites which operator said it. The brain gives the technique —
YOU add what makes sense for our products and customers.

## The safety rules (the short version)

- Claude will NEVER send an email/DM to a real person, spend money, or touch
  Brady's systems without a human saying yes. If it stops and asks — that's it
  working correctly, not being difficult.
- Passwords and keys only ever go in the `.env` file. Never paste a password
  into the chat.
- You build YOUR OWN stuff in this workspace. Changes to Brady's stuff go
  through Brady.

## Tiny glossary

- **Workspace / repo** — the folder your projects live in, with save-history.
- **Git** — the save-history system (like version history in Google Docs).
- **GitHub** — Google Drive for code; where the team shares projects.
- **API / API key** — a way for programs to talk to a service; the key is the
  password for it. You'll rarely need to think about these — Claude handles it
  and will tell you if you ever need to get a key for something.
- **MCP** — the plug that connects Claude to tools like the knowledge brain.

## When something breaks

1. Tell Claude what you saw, in your own words. It fixes most things itself.
2. If Claude is stuck: quit Claude Code, reopen it in the workspace folder,
   try again.
3. Still stuck: message Brady with what you were doing and what Claude said last.
